## 启动

ssh root@178.110.22.6

## 参数(全是环境变量,想改直接加)
| 变量 | 默认 | 含义 |
|---|---|---|
| `NUM_ROLLOUT` | 3000 | 总轮数(=步数,1 步/轮) |
| `SAVE_INTERVAL` | 20 | 每 N 步存 ckpt(**每份 ~172G,注意磁盘只剩 229G**) |
| `RESP_LEN` | 4096 | 单轮对话生成上限(retool 多轮语义) |
| `MAX_TOKENS_PER_GPU` | 16384 | 多轮样本总上下文预算(CP×该值) |
| `ROLLOUT_TEMP` | 1.0 | 采样温度(官方 retool 口径,勿轻易降——组内方差=学习信号) |

## 查进度
```bash
docker exec czl_slime bash -lc 'grep -c "rollout [0-9]*: {" /home/c00954327/slime-run/logs/retool_run100.log'   # 已完成轮数
docker exec czl_slime bash -lc 'grep "rollout [0-9]*: {" /home/c00954327/slime-run/logs/retool_run100.log | tail -1'  # 最新指标(看 raw_reward 涨没涨、truncated 降没降)
tail -20 对应日志   # 实时尾部
```

## 停止(注意方括号写法,防 pkill 误杀自己)
```bash
docker exec czl_slime bash -lc 'pkill -9 -f "train[.]py"; pkill -f "run-qwen3.5-9B-npu-retool[.]sh"; sleep 3; ray stop --force; pkill -9 -f "rayle[t]"'
```
**停止前必读**:ckpt 只在 `SAVE_INTERVAL` 的步点落盘——中途停止=该步点之后的训练进度全部丢弃(权重回退到上次存盘/初始基线)。要先保进度再停,把 SAVE_INTERVAL 设小、跑过下一个步点再停。

## 经验数字(11-20~11-23 实测,供排期)
- 每轮 ~2.5 小时(90% 是多轮工具生成,训练步只占 13 分钟)
- 学习曲线:第 0 轮全错 → 第 30 轮 raw_reward 0.52(~68% 答对)、截断 48.8%→0.4%
- 启动到首步 ~45 分钟;8 卡全占;断网不影响 w13 上的进程
